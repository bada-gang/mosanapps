GitHub 연결

고친 내용을 홈페이지에 반영하려면 GitHub 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않습니다.

토큰 만드는 방법
  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → mosanapps만 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만들어진 토큰(github_pat_로 시작)을 위 칸에 붙여 넣기

상단 문구와 레이아웃

제목에서 *별표*로 감싼 글자는 파란색으로 강조되고, 줄을 바꾸면 홈페이지에서도 줄이 바뀝니다.

앱 목록

왼쪽 손잡이(⠿)를 끌거나 ▲▼ 버튼으로 순서를 바꿉니다. '표시'를 끄면 홈페이지에서 숨겨집니다.
